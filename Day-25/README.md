# Day 25

## Problem
Word (59A)

## Platform
Codeforces

## Difficulty
800

## Approach

- Read the given string.
- Count the number of uppercase and lowercase letters.
- If uppercase letters are more, convert the complete string to uppercase.
- Otherwise, convert the complete string to lowercase.
- Print the resulting string.

## Example

Input:
```text
HoUse
```

Output:
```text
house
```

## Time Complexity

O(n)

## Space Complexity

O(1)

## Concepts Used

- Strings
- Character handling
- `isupper()`
- `toupper()`
- `tolower()`
- Conditional statements
